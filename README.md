### 📊 Project Overview
Organizations frequently treat AI deployment as a standard software upgrade rather than a systemic and cultural transformation. This repository hosts the foundational research and literature synthesis used to investigate AI adoption barriers through the **Human-Technology-Organization (HTO)** framework. 

This theoretical research was used in conjunction with a custom-built Python ETL pipeline (Pandas, NumPy) to analyze and categorize over 16,000 real-world AI incident logs into socio-technical failure modes.
